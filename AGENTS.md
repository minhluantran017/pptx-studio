# Project instructions

- Keep generated slides editable: prefer native PowerPoint text, shapes, connectors, and charts.
- Use the shared theme and layout helpers for consistent margins and typography.
- Keep profile differences limited to deliberate design tokens and content choices.
- For requests to create a PowerPoint, create PPTX slides, build a slide deck, revise presentation slides, or visually QA a deck, read and follow `.claude/skills/pptx-studio/SKILL.md`.
- Run `npm run build:sample` to refresh the sample deck.
- Run `npm run render` and inspect `output/contact-sheet.png` when LibreOffice and Poppler are installed.
